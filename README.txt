AUDIO FILES - put these exact filenames in this folder (assets/audio/):

  ambient.mp3     looping background music (cozy, warm, soft acoustic, minimal percussion)
  enter.mp3       played once when the visitor enters the studio (soft fabric/yarn rustle)
  transition.mp3  played when a new section is reached (gentle whoosh)
  hover.mp3       played when hovering a project card (tiny hook click / thread tick)
  click.mp3       played when pressing a button (soft tap)

Rules:
- Names are case-sensitive on GitHub Pages. Use lowercase .mp3.
- Only use audio you made or that is licensed for reuse (CC0 / royalty-free with a license
  that allows websites). Check the license before uploading.
- Keep effects under ~1 second and ambient.mp3 under ~5 MB so the page stays light.
- To change a filename or volume, edit AUDIO_CONFIG at the top of script.js.
- Missing files are fine: the site runs silently and logs "[CROCHET AUDIO]" in the console.
